# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchases** across multiple product categories.

The objective is to identify **spending patterns, customer segments, product preferences, subscription behavior, and discount impact** to generate actionable business insights and support data-driven decision-making.

---

## 🧩 Dataset Summary

| Property | Details |
|---|---|
| Rows | 3,900 |
| Columns | 18 |
| Missing Data | 37 missing values in Review Rating |
| Missing Value Treatment | Median imputation by category |

### 🔑 Key Features

- **Customer Demographics:** Age, Gender, Location, Subscription Status
- **Purchase Details:** Item Purchased, Category, Purchase Amount, Season, Size, Color
- **Shopping Behavior:** Discount Applied, Previous Purchases, Review Rating, Shipping Type
- **Purchase Frequency:** Frequency of Purchases

---

## 🐍 Exploratory Data Analysis

Python was used for data loading, cleaning, validation, and feature engineering.

### Steps Performed

**1. Data Loading & Cleaning**
- Loaded the CSV dataset using Pandas.
- Checked data types, missing values, and duplicate records.
- Removed duplicate records.
- Standardized column names to `snake_case`.
- Handled missing values in `review_rating`.

**2. Feature Engineering**
- Created `age_group` by grouping customers based on age.
- Derived `purchase_frequency_days` to analyze buying intervals.

**3. Data Validation**
- Checked consistency between `discount_applied` and `promo_code_used`.
- Validated the cleaned dataset before database integration.

## 🧮 SQL Business Analysis

PostgreSQL was used to answer important business questions, including:

1. 💰 **Revenue by Gender**  
   Compared total revenue generated by male and female customers.

2. 🏷️ **High-Spending Discount Users**  
   Identified customers who used discounts while spending above the average purchase amount.

3. ⭐ **Top 5 Products by Rating**  
   Found products with the highest average review ratings.

4. 🚚 **Shipping Type Comparison**  
   Compared purchase amounts between Standard and Express shipping.

5. 👥 **Subscribers vs. Non-Subscribers**  
   Compared spending and revenue generated by subscribed and non-subscribed customers.

6. 💸 **Discount-Dependent Products**  
   Identified products with the highest proportion of discounted purchases.

7. 🔁 **Customer Segmentation**  
   Classified customers into:
   - New
   - Returning
   - Loyal

8. 🛒 **Top 3 Products per Category**  
   Identified the three most purchased products within each category.

9. 📈 **Repeat Buyers & Subscriptions**  
   Analyzed whether customers with more than five purchases were more likely to subscribe.

10. 🎯 **Revenue by Age Group**  
    Calculated revenue contribution across different customer age groups.
